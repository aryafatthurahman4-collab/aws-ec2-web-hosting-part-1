## Urutan belajar (ringkas)

```text
Linux
 -> Git / GitHub
 -> Cloud Fundamentals (IaaS/PaaS/SaaS, region/AZ, HA, IAM)
 -> AWS (EC2, S3, RDS, VPC, ALB)
 -> Docker (image, container, Dockerfile, Compose)
 -> Kubernetes (Pod, Deployment, Service, ConfigMap, Secret)
 -> Terraform (provider, resource, state, module, init/plan/apply/destroy)
 -> CI/CD (GitHub Actions, Jenkins, CodePipeline)
 -> Monitoring (Prometheus, Grafana, ELK)
 -> HTTPS + DNS (Route 53, ACM, Let's Encrypt)
 -> Optimasi biaya & keamanan
```
